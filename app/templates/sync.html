进入应用

请选择初始化来源。当前版本使用新的数据目录；旧数据库保留，不自动读取。使用远端会替换当前活动数据，替换前保留副本。有未上传提交或冲突草稿时，必须先处理同步才能重新初始化。

仓库与自动同步设置

使用独立私有仓库。HTTPS 复用系统 Git 凭证管理器，SSH 复用系统密钥。不要在地址中填写 Token；仓库可见性请在托管平台确认。

认证失败时，请先在本机终端完成 Git 凭证管理器登录或 SSH 密钥／主机信任配置，再测试连接。应用不会弹出登录窗口或保存访问令牌。

处理数据冲突

选择先保存到独立草稿。全部冲突处理并校验通过后，确认总览才会替换数据库。
