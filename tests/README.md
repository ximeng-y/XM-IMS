# 本地备份回归测试

这组测试仅覆盖共享进程执行器边界和一条真实本地备份流程，使用 Python 标准库
`unittest`，不引入测试框架依赖。

## 运行

需要 Python 3.12、`requirements.txt` 中的现有依赖，以及可用的 Git。
在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -B tests/run.py
```

使用其他已安装项目依赖的 Python 环境时，执行 `python -B tests/run.py`。
未来测试 CI 可以调用同一入口；当前未接入 CI。

运行器会在项目 `.XMTEMP` 下创建独立临时目录，并为子进程设置隔离的数据目录和
程序目录。不会使用真实店铺数据、远端仓库或 GitHub 凭据，结束后清理本次测试目录。
不要绕过运行器直接执行 `unittest discover`，测试会拒绝未隔离的环境。

## 覆盖范围

| 测试文件 | 负责内容 |
| --- | --- |
| `test_processes.py` | 无输入时取得 EOF；空输入及大块二进制输入；工作目录与环境；退出码和双路输出；大输出排空；虚构凭据类输出不写临时文件；直接子进程、管道已关闭以及后代分别持有输出管道时的超时返回；真实 Git 的返回码与错误转换 |
| `test_local_backup.py` | 创建临时首店；无远端时首次本地备份；故意触发一次进程超时后的任务锁释放和重试；幂等回放；相同内容不新增版本；从真实 Git 提取备份并核对清单及店铺数据 |

共 14 个用例。超时用例检查是否在宽松的期限内返回，不做精确性能排名。
运行器另外设置 45 秒上限，避免进程回归导致测试本身无限等待；Windows 下使用
Job 对象清理测试进程树。

这组测试不覆盖远端同步、网络连接、冲突处理、浏览器按钮交互和安装更新。
